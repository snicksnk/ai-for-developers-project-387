# Lighthouse — журнал правок

Сюда команда переносит подтверждённые правки по итогам ночных отчётов Lighthouse.
Каждая запись — дата отчёта, счёт, что решили чинить, ссылка на задачу/PR.

Формат записи:

```
## YYYY-MM-DD

Счёт (desktop): perf __ / a11y __ / best-practices __ / seo __

Правки:
- [ ] <что> — <почему> — #<issue/PR>
```

## 2026-08-31 — базовая настройка

отчёт появится в issue с меткой `lighthouse`. Здесь фиксируем правки начиная со
следующего прогона.
